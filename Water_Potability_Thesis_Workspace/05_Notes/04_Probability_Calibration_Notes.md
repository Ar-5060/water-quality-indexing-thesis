# Lesson 04 — Probability Calibration

## Purpose

A classifier can rank samples reasonably well but still produce probabilities that do not match observed frequencies. Calibration checks and adjusts the probability estimates.

## Methods compared

1. **Uncalibrated:** original model probabilities.
2. **Sigmoid calibration:** fits a logistic mapping to model scores.
3. **Isotonic calibration:** fits a non-parametric monotonic mapping.

The script records out-of-fold (OOF) calibration predictions and full-fit calibrators for later use.

## Why OOF matters

An OOF probability for a calibration row is generated by a calibration model that did not fit on that row. This reduces the optimism that can occur if the same row is used both to fit and assess the calibrator.

- Use `*_sigmoid_oof` for threshold selection and selective cut-off selection.
- Do not use `*_sigmoid_full_fit` to select thresholds on the same calibration rows.
- During final outer-test evaluation, use the saved fold-specific full-fit sigmoid calibrator to transform that fold's test scores.

## Fold 1 example

Recorded Fold 1 calibration results:

| Model | Brier uncalibrated | Brier sigmoid | Brier isotonic |
|---|---:|---:|---:|
| Majority Baseline | 0.23775 | 0.23775 | 0.23775 |
| Logistic Regression | 0.25224 | 0.23783 | 0.23937 |
| Random Forest | 0.21298 | 0.21190 | 0.21365 |
| MLP | 0.20618 | 0.20653 | 0.20488 |

This is only one fold. The best calibration method can differ by metric and fold. Sigmoid was fixed as the primary method for the later decision pipeline; that does not mean it improves every metric in every fold.

## Other metrics

- Brier score: lower is better for probability error.
- Log loss: penalises inaccurate and overconfident probabilities.
- ECE: an approximate summary of calibration gap; interpretation depends on binning.

## Defence explanation

**Does calibration improve ROC-AUC?**  
Calibration primarily changes probability values, not necessarily the ranking. A monotonic calibration mapping may leave ROC-AUC nearly unchanged.

**Why retain uncalibrated and isotonic results?**  
They provide comparison and sensitivity evidence. The primary downstream method remains the predeclared sigmoid method.
